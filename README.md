## 📖 О проекте

**AI Insight** — это браузерное расширение для Chrome, которое превращает работу с нейросетями в удовольствие. Больше не нужно держать промпты в заметках, вставлять их вручную или каждый раз писать одно и то же.

Сохраняйте лучшие запросы в личную библиотеку, группируйте их по тегам и категориям, создавайте контекст-профили для разных задач — и вставляйте нужный промпт в любой AI-чат за секунду.

### 🎯 Проблема, которую решает AI Insight

- 😩 Постоянно писать одно и то же в ChatGPT / Claude / DeepSeek
- 📋 Держать промпты в блокноте и копипастить их вручную
- 🔀 Переключаться между вкладками, чтобы найти нужный запрос
- 🧠 Забывать, какой промпт сработал лучше всего

### ✅ Решение

- 📚 Единая библиотека промптов со всеми вашими запросами
- 🧠 Контекст-профили для работы, учёбы, кода и творчества
- ⌨️ Мгновенная вставка через `/` или `Alt+P`
- 🌐 Работает на 10+ AI-платформах без дополнительной настройки

## ✨ Возможности

### 📚 Библиотека промптов
Сохраняйте часто используемые запросы в одном месте. Организуйте их по тегам и категориям, добавляйте описания — и находите нужный промпт за секунды.

### 🧠 Контекст-профили
Создавайте профили с контекстом для разных сценариев: работа, учёба, программирование, творчество. Переключайтесь между ними одним кликом — и весь набор промптов меняется вместе с вами.

### ⌨️ Мгновенная вставка
Два способа вставить промпт в любой чат:
- Нажмите **`/`** в поле ввода — откроется палитра промптов
- Нажмите **`Alt+P`** в любом месте страницы — палитра появится поверх интерфейса

### 🪟 Боковая панель
Полноценный менеджер промптов в side panel Chrome — открывайте библиотеку, не покидая текущую вкладку.

### 💾 Локальное хранение
Все промпты и профили хранятся локально в вашем браузере. Никакой отправки данных на сервер — приватность превыше всего.
